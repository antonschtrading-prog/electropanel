# Фасады аппаратов Electropanel: правила каталога и источников

## Цель

Показывать на DIN-рейке изображение **точного артикула** выбранного аппарата.
Пока лицензированного изображения нет, интерфейс использует авторский SVG-эскиз
и прямо обозначает, что это не заводская фотография.

## Обязательная идентификация

Изображение можно подключить только при одновременном совпадении:

1. `maker` — изготовитель;
2. `series` — серия;
3. `sku` — точный артикул;
4. `kind` — тип аппарата;
5. `poles` — число полюсов;
6. `modules` — ширина в DIN-модулях;
7. `widthMm` — заявленная ширина корпуса в миллиметрах.

Отсутствие хотя бы одного обязательного признака не позволяет считать
фотографию подтверждённой. Габариты должны поступать из каталога/паспорта,
а не вычисляться по пикселям изображения.

## Права и происхождение

Для каждого локального изображения требуется:

- `src` — файл внутри `assets/device-fronts/`, PNG/JPEG/WebP;
- `assetType` — `FRONT_PHOTO` либо `FRONT_RENDER`;
- `rightsStatus` — `PERMISSION_RECORDED`;
- `rightsEvidenceUrl` — HTTPS-ссылка на подтверждение прав;
- `productEvidenceUrl` — HTTPS-ссылка на карточку изделия или официальный документ;
- `reviewedAt` — дата сверки в формате YYYY-MM-DD.

Пример **структуры**, не реальный разрешённый к публикации объект:

```js
{
  maker: 'Example Manufacturer',
  series: 'Example Series',
  sku: 'EXAMPLE-001',
  kind: 'MCB',
  poles: 1,
  modules: 1,
  widthMm: 18,
  src: 'assets/device-fronts/example-001.webp',
  assetType: 'FRONT_PHOTO',
  rightsStatus: 'PERMISSION_RECORDED',
  rightsEvidenceUrl: 'https://example.org/rights',
  productEvidenceUrl: 'https://example.org/product',
  reviewedAt: '2026-11-17'
}
```

**Не копировать** изображения с сайтов производителей без проверки разрешения
на повторное использование. Не регистрировать шаблонный пример как реальный товар.

## Порядок подключения

1. Подтвердить артикул и габариты по технической документации.
2. Проверить права на изображение и зафиксировать ссылку на разрешение.
3. Сохранить оригинальный файл в локальном каталоге разрешённых изображений.
4. Зарегистрировать запись в `EP_MANUFACTURER_FRONT_ASSETS_V1` через
   `manufacturer-visual-library-v1.js`.
5. Проверить `epManufacturerFrontResolveV1`: статус `REVIEWED_IMAGE`
   разрешён только при полном совпадении.
6. Прогнать JavaScript-тесты, инженерную валидацию и браузерную интеграцию.
7. Проверить вид на узкой и широкой DIN-компоновке.

## Важное разграничение

Подтверждённое изображение **не подтверждает** монтажную пригодность,
электрические номиналы, селективность, тепловые зазоры или геометрию корпуса.
Эти проверки остаются самостоятельными проектными задачами.

Экспорт `*_front_din_audit.csv` предназначен для поиска отсутствующих
артикулов, неверных габаритов и неподтверждённых изображений.
