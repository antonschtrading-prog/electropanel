# Интегрированный инженерный контур: ток, кабель, защита, падение напряжения

## Состав этапа
1. `load-current-v1.js`: ток нагрузки Ib для однофазных и симметричных трёхфазных цепей, с сохранением формулы и исходных данных.
2. `cable-reference-v1.js`: ограниченная справочная таблица сечений Cu/PVC B1/C, только при явно подтверждённых условиях.
3. `voltage-drop-design-v1.js`: отдельный расчёт падения напряжения по длине трассы, активному и реактивному сопротивлению жилы при расчётной температуре, cos φ и заданному инженером предельному проценту.
4. `circuit-design-review-v1.js`: единая проверка условий Ib ≤ In, In ≤ Iz, Icn ≥ Ik, справочного сечения и падения напряжения для каждой цепи. Проверка каждого условия независима: неизвестное не трактуется как успешное.
5. `circuit-design-review-ui-v1.js`: таблица 15 показателей, быстрый переход к цепи, редактирование исходных данных падения напряжения, CSV-выгрузка.
6. `design-work-queue-v1.js`: приоритетная очередь инженерных задач: сначала выявленные противоречия, затем недостающие исходные данные, затем контроль актуальности.
7. Интеграция в инженерный JSON, печатный отчёт, сводный журнал замечаний, общую проверку проекта и тестирование CI.

## Расчёт падения напряжения
Для однофазной цепи: ΔU = 2 × Ib × Lкм × (R × cosφ + X × sinφ), при документированной эквивалентности фазного и обратного проводников.

Для симметричной трёхфазной цепи: ΔU = √3 × Ib × Lкм × (R × cosφ + X × sinφ).

Входы: Ib, L, U, R, X, cosφ, максимальное ΔU%, подтверждение источника R/X и длины, подтверждение обратного проводника для 1Ф. Модель **не** извлекает R/X из одного только сечения, не предполагает фиксированного напряжения или коэффициента мощности и не подменяет заданный инженером предел универсальной нормой.

## Границы достоверности
Проверки Ib/In, In/Iz и Icn/Ik — необходимая часть подбора, но не полный набор условий. Для окончательного проектного решения также необходимы проверка защитных характеристик, времён отключения, кабельных поправок, петли КЗ, нагрева, схемы заземления, координации аппаратов и применимых нормативных документов. Отдельные справочные данные остаются явно обозначенными как справочные.

## Автоматическая проверка
- Формулы 1Ф/3Ф, активная и реактивная составляющие, границы заданного лимита.
- Запрет расчёта при отсутствующих документированных исходных данных.
- Сохранение параметров без мутаций исходного проекта.
- Конфликты защиты, кабеля и отключающей способности.
- Приоритеты очереди задач, обработка отсутствующих данных.
- Безопасность HTML, CSV, интеграция интерфейса, инженерного отчёта и журнала замечаний.

Основная ветка сохраняется без изменений до отдельного согласования.
