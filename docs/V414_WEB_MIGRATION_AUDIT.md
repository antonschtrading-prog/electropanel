1. Найти и идентифицировать **реальные исходники v4.14** (либо явно учесть отсутствие), не смешивая с отдельной веткой 0.1.
2. Сохранить безопасный откат и провести полный `node --check`, `node --test tests/*.test.js`, проверить CI и вручную главные сценарии браузера/JSON.
3. Для каждого перенесённого нормативного расчёта: источник/редакция нормы, область применения, тестовые данные, ожидаемое значение и статус неопределённости.
4. Не переводить `PRELIMINARY_PASS` в статус допуска проекта; не допускать молчаливого сброса устаревших расчётов.
5. Полный перенос v4.14 пока **не подтверждён**; PR #1 остаётся draft до проверки.

## Блок документальной целостности кабельных паспортов — 13.11.2026

- Перенесены из архива v4.14 функции документальной сверки: `verify_document_bytes` из `electropanel/evidence_v34.py` и `cable_provenance_v45` из `electropanel/tt_cable_v45.py` в чистый JavaScript `cable-evidence-v45.js`.
- Целостность предъявленных байтов проверяется локально по SHA-256 через WebCrypto; сравнение с введённым пользователем хешем **не доказывает, что документ опубликован изготовителем**.
- В интерфейсе «Документы» добавлена локальная проверка файла (до 1 МБ); исходный файл и его байты **не загружаются в облако и не сохраняются в проекте**. Вводимая сумма является декларацией пользователя.
- Функция проверки происхождения кабельных характеристик требует явных характеристик, документа, совпадения хеша и независимых заявленных проверок; даже при числовом PASS возвращает `ready_for_design=false` и `ready_for_installation=false`. Её расширенная форма и привязка к реальному кабельному подбору — отдельные задачи.
- Браузер должен иметь безопасный контекст HTTPS для WebCrypto. При отсутствии API операция должна **отказать**, а не ложно вернуть PASS. GitHub Pages использует HTTPS. Полное end-to-end на опубликованном сайте требует отдельной проверки.
- В тестах проверены исходные эталоны из `test_v34.py` / `test_v45.py`: верный SHA, подмена файла, неверный Base64, пропущенный/недостоверный источник, недопустимые характеристики. Данные тестовых паспортов **не являются настоящими паспортами изготовителя**.
