# Каталожные габариты в вариантах DIN-компоновки

Модуль `cabinet-apparatus-geometry-v1.js` проверяет доступные в каталоге габариты аппаратов: `geometry.widthMm`, `geometry.heightMm`, `geometry.depthMm` (или одноимённые поля верхнего уровня). Артикул и модульная ширина сверяются с аппаратом, участвующим в проверенном DIN-предпросмотре.

**Отсутствующие значения не заполняются выдуманными числами.** Если известна только модульная ширина, показывается номинальный шаг 18 мм на модуль с пометкой об условности. Если каталог сообщает ширину больше доступного номинального DIN-пролёта, вариант блокируется. При заданных `mountingBandMm` или `depthLimitMm` проверяются известные высота и глубина. Неизвестные размеры остаются статусом `UNKNOWN`, а не подтверждением пригодности корпуса.

Варианты компоновки используют этот аудит до включения в список предложений. Блокирующие несоответствия отбрасываются. Для выбранного варианта показывается число аппаратов с полными и неполными габаритами, отдельная условная DIN-схема и CSV-ведомость.

SVG различает известные и неизвестные габариты цветом, экранирует идентификаторы и не изображает товарные фотографии. CSV защищает от формульной интерпретации строк. Никаких неподтверждённых паспортных размеров производителей не добавляется.

**Ограничения:** расчётный DIN-шаг не является габаритным чертежом изделия. Пока нет проверенной геометрии конкретного корпуса, свободных зон, допустимых условий монтажа и теплового расчёта, нельзя считать посадку аппаратов подтверждённой. Результаты служат для сравнения вариантов, не для выдачи готового монтажного решения.
