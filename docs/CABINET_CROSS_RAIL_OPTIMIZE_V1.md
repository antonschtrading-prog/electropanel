# Межрядная оптимизация DIN-компоновки v1

`cabinet-cross-rail-optimize-v1.js` предлагает перемещения **целых аппаратов** между DIN-рейками с целью уменьшить количество межрядных связей, явно объявленных в проекте. Это отдельное действие пользователя «Сократить связи между DIN-рейками», а не автоматическое изменение при выборе корпуса.

Алгоритм использует `epDraftBoardPlanV1` и `epCabinetConnectionProximityV1`. Сначала проверяется исходная компоновка. Для каждого аппарата без ручной фиксации перебираются допустимые позиции на других рейках. Выбирается строго улучшающее перемещение по числу межрядных связей, затем по номинальным промежуткам связанных аппаратов. Перебор повторяется ограниченное число проходов.

**Инварианты:**
- ручные позиции не изменяются;
- число и вместимость реек не меняются;
- артикула, номиналы, цепи и логические связи не изменяются;
- пересечения и выход за границы реек запрещены;
- проект не изменяется до явного подтверждения;
- проверяется результат штатным движком компоновки;
- при наличии геометрии корпуса выполняется аудит размещения; если аудит недоступен, результат блокируется;
- если количество межрядных связей не уменьшилось, исходная компоновка сохраняется;
- каждое применение создаёт контрольную точку для отмены.

Оптимизация не определяет реальные трассы кабелей и не подтверждает тепловые условия, соответствие производителя корпуса или электрическую селективность. Подсчёт основан только на **объявленных** связях. Список изменений и исходный проект остаются доступными для проверки.

## Интерактивный предпросмотр

Первое нажатие «Предпросмотр межрядной оптимизации» **не меняет проект**. В панели отображаются сравнение межрядных связей, число перестановок, SVG-эскиз реек (жёлтый — перемещение, зелёный — без изменений), раскрываемый список прежних/новых позиций. Доступны отдельные кнопки экспорта CSV и SVG.

Кнопка «Применить предложенную компоновку» запускает повторный расчёт по текущему проекту, сравнивает изменения с исходным предложением, перепроверяет идентичность аппаратов и требует явного подтверждения. Если проект изменился с момента предпросмотра, применение блокируется. После успешного применения предложение удаляется, а операция доступна для отмены через историю.

Модуль `cabinet-reflow-preview-v1.js` адаптирует результат оптимизатора к общему контракту `epCabinetOptionPreviewV1`; используются существующие рендер SVG и CSV, без параллельной логики проверки размещения.
