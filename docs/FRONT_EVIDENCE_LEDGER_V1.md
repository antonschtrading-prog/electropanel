# Сквозная ведомость подтверждений фасадов оборудования

## Назначение
Новый модуль `front-evidence-ledger-v1.js` формирует единый реестр для фактически размещённых в щите аппаратов. Он работает поверх `epCabinetArticleReconciliationV1`, не заменяет электротехнические расчёты и не меняет состав аппаратов.

## Связь между данными
- Группировка по точному артикулу из компоновки; количество аппаратов и идентификаторы сохраняются.
- Для каждого артикула — производитель, серия, тип, ширина корпуса, ширина DIN-места.
- Раздельные статусы заводского изображения и геометрии: `REVIEWED_IMAGE`, `STYLIZED_ONLY`, `ASSET_REJECTED`, `CATALOGUE_MISSING`; `UNKNOWN`, `DECLARED_WITHIN_SLOT`, `EXCEEDS_DIN_SLOT`.
- Подтверждённые изображения показываются только с локальными безопасными путями; эскиз не считается заводской фотографией.
- Источник изображения и дата его проверки сохраняются отдельно от паспортных размеров.
- В CSV выгружается явный `engineering_approved=NO`; потенциальные формулы экранируются.
- При ошибках поиска, несовпадении артикула, отклонении изображения и превышении ширины DIN-места реестр имеет `BLOCKED`, но не изменяет проект.

## Доступ в интерфейсе
В галерее фасадов доступна кнопка **«Скачать ведомость подтверждений фасадов CSV»**. Она строит реестр по текущему состоянию проекта в момент нажатия и сохраняет `*_front_evidence_ledger.csv`. Существующая ведомость фасадов и аудит DIN сохранены.

## Ограничения
Пустой реестр заводских изображений не подменяется фиктивными файлами. Фактическая пригодность монтажа, подтверждение производителем, лицензионная экспертиза и электротехническая сертификация не выводятся из изображения.

## Контроль
Добавлены 53 сценария модели и CSV плюс браузерные интеграционные проверки; обязательные GitHub Actions проверяют сборку, тесты и интерфейс.
