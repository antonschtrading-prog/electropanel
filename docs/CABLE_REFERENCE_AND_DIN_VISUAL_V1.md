# Справочный подбор сечения и графика DIN — цикл разработки

## Справочный кабельный расчёт
`cable-reference-v1.js` связан с сохранённым расчётным `Ib` и номиналом `In` выбранного автомата. Модуль выводит сравнительную таблицу шести сечений 1,5–16 мм² для способов прокладки B1 и C в строго ограниченном контексте: Cu/PVC, два нагруженных проводника, температура воздуха 30°C, одиночная негруппированная цепь, отсутствие дополнительных коэффициентов. Условия вводятся и подтверждаются инженером. Несовпадающий контекст и отсутствующие данные не подменяются догадками.

Значения взяты из ранее внедрённой справочной выборки `reference-ampacity-v38.js`; официальная числовая редакция таблицы и поправки требуют независимого подтверждения. `Ib ≤ Iz` и `In ≤ Iz` — только частичные арифметические условия, не окончательный выбор сечения. Результат не записывает сечение в проект автоматически и не утверждает его соответствие требованиям. Остальные проверки (условия отключения, падение напряжения, поправочные коэффициенты, стойкость к КЗ, способ прокладки и др.) остаются самостоятельными.

## Связанные части
- Редактор кабельного контекста для выбранной цепи; запись через общие undo/autosave.
- Вывод справочных вариантов и отклонённых сечений в интерфейсе.
- Раздел кабелей в инженерном JSON, журнале замечаний и печатной ведомости.
- Иллюстрированная лицевая панель аппаратов на DIN: оригинальная стилизованная графика с цветовым акцентом производителя. Это не точные паспортные изображения и не CAD-модели конкретных серий.
- Тесты граничных значений, недопустимых условий, сохранения без мутаций, HTML-экранирования и связности интерфейса.

## Следующий инженерный блок
Проверить официальный нормативный источник, определить паспортную структуру кабельных серий и способа прокладки, подключить расчёт падения напряжения и проверку защиты к единому выбору кабеля. Реалистичность аппаратов улучшать на основе документированных габаритов и изображений конкретных артикулов; не подменять их стилизованной графикой.
