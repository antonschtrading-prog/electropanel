# Сопоставление DIN-компоновки с корпусами по полезным размерам

Модуль `cabinet-enclosure-match-v1.js` сравнивает предложенное расположение аппаратов с **явно введёнными полезными размерами** корпуса. Данные вводятся в поле JSON рядом с предпросмотром межрядной оптимизации. Пример структуры:

```json
[
  {
    "id": "catalogue-enclosure-001",
    "manufacturer": "Название изготовителя",
    "article": "Проверенный артикул",
    "usableInterior": {"widthMm": 400, "heightMm": 500, "depthMm": 150},
    "railCapacity": 2
  }
]
```

Числа в примере — **только пример структуры**, а не паспортные данные какого-либо изготовителя. В реальном проекте используйте подтверждённые данные каталога или документации. Поля могут отсутствовать, но тогда соответствующий параметр остаётся `UNKNOWN`.

Для каждой DIN-компоновки вычисляются требования по ширине, высоте, глубине и числу реек с явно обозначенными **условными проектными припусками**. Проверки имеют значения `PASS`, `FAIL` или `UNKNOWN`. Итоговый статус кандидата: `PRELIMINARY_MATCH`, `REJECTED` либо `UNVERIFIED`. Если габариты аппаратов неизвестны, вариант не получает `PRELIMINARY_MATCH`, даже если доступные размеры корпуса велики. При недостаточном известном размере результат отклоняется.

Список кандидатов не изменяет проект и не влияет на электрические расчёты. Изменение исходных данных проекта или списка корпусов делает предложение устаревшим перед применением. CSV-экспорт содержит поосевые требования, доступные размеры, результаты проверок и `confirmed_fit=NO`.

**Ограничение:** совпадение полезных габаритов и числа реек не означает подтверждения конкретного изделия. Крепления, реальная геометрия DIN-узлов, зоны кабельных вводов, тепловые условия и монтажные ограничения не подтверждаются этой сравнительной функцией. При отсутствии достаточных данных нельзя автоматически утверждать корпус к установке.

## Упрощённый ввод без JSON

Можно указать по одному корпусу на строку, разделяя семь полей точкой с запятой:

```text
Корпус-1; Изготовитель; Артикул; 400; 500; 150; 2
Корпус-2; Изготовитель; Артикул; 600; 700; ; 3
```

Поля: ID, изготовитель, артикул, **полезная** ширина, **полезная** высота, **полезная** глубина (мм), число DIN-реек. Пустые размеры остаются неизвестными. Десятичная запятая допускается. Примеры чисел не являются паспортными данными. Модуль `cabinet-enclosure-input-v1.js` ограничивает ввод 100 кандидатами и валидирует данные до расчёта.
