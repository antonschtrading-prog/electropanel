# Расчёт тока нагрузки: первый рабочий контур

Модуль `load-current-v1.js` вычисляет заявленный расчётный ток `Ib` по явно введённым параметрам. Режим 1Ф: `Ib = P * 1000 * kd / (U_LN * cosφ * η)`. Режим 3Ф: `Ib = P * 1000 * kd / (√3 * U_LL * cosφ * η)`. `P` — активная мощность в кВт; если задана механическая выходная мощность, КПД учитывает её преобразование. При электрической входной мощности `η=1`. `kd` — введённый коэффициент спроса, а не автоматически установленный нормативный коэффициент.

Трёхфазная формула применима к симметричной установившейся нагрузке. Значения напряжения, коэффициента мощности, КПД и спроса вводятся пользователем, без молчаливых значений по умолчанию. Отрицательные, нулевые, нечисловые и недопустимые значения блокируются. Режим расчёта сверяется с фазностью цепи. Результат округляется вверх до 0,001 А, исходные параметры и формула сохраняются в цепи.

В `protection-workbench-v1.js` сохраняется прослеживаемость расчёта. `Iz` кабеля и `Ik` короткого замыкания не подменяются расчётным `Ib`. После изменения исходной нагрузки сохранённый расчёт помечается устаревшим и требует повторной проверки. Результат включён в инженерный JSON и печатный отчёт.

## Границы применимости

Этот модуль выполняет только арифметику установившегося тока. Он не рассчитывает пусковые токи, высшие гармоники, режимы электропривода, несинусоидальные нагрузки, несимметрию трёхфазной сети, тепловой режим и нормативный выбор защитных аппаратов. Эти проверки требуют самостоятельных расчётных моделей и документированных исходных данных.
