# Electropanel: библиотека фасадов и физическая геометрия DIN v1

## Принцип
Визуальная достоверность, геометрические параметры и электротехнический расчёт независимы. Стилизованное изображение не является заводской фотографией или 3D-моделью. Паспорта устройств и права на фотографии проверяются раздельно.

## Реализовано
- Точный реестр по производителю и артикулу, дополнительная сверка серии, вида, полюсов, модулей, ширины корпуса и даты источника.
- Реестр заводских фотографий **пока пуст**. Приложение автоматически остаётся на собственных стилизованных SVG, если фото отсутствует либо не прошло проверку.
- Разрешаются только локальные PNG/JPG/WebP в каталоге assets/device-fronts с документированными правами и ссылкой на источник изделия; адреса удалённых изображений и SVG блокируются.
- Корпусные габариты Ш×В×Г не выводятся автоматически из графического представления. Шаг сетки составляет условные 18 мм на DIN-модуль, а реальная ширина берётся из каталога.
- Отдельный аудит проверяет фактическую ширину относительно занимаемых модулей, совпадение заявленного числа модулей, переполнение и наложения.
- Неизвестные значения не подменяются выдуманными; предупреждения выводятся в превью компоновки. Не подтверждаются тепловой режим, монтажные зазоры и посадка в конкретный шкаф.

## Для добавления реального фото
Сначала получить разрешение на использование фото. Добавить сверенный растровый файл в assets/device-fronts/. В EP_MANUFACTURER_FRONT_ASSETS_V1 зарегистрировать maker, series, sku, kind, poles, modules, widthMm, src, assetType, rightsStatus=PERMISSION_RECORDED, rightsEvidenceUrl, productEvidenceUrl и reviewedAt. Сверить физическое существование файла, устройство и лицензию. Запустить Node-тесты и интеграционные проверки GitHub Actions. Не менять электрические расчёты по внешнему виду.

## Остаётся
Заводские разрешённые фасады по приоритетным сериям, точная геометрия корпусов, модели шкафов, вентиляционные зазоры, адаптивное мобильное сравнение. Это отдельная очередь, а не объявленная готовность 3D.
