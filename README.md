# Electropanel — тестовая веб-версия

Браузерный конструктор электрических щитов (рабочий прототип, **не** монтажная документация).

## Публикация

1. Загрузить в корень репозитория файл `electropanel_web_preview_v0.11.zip` через GitHub **Add file → Upload files**.
2. В репозитории открыть **Settings → Pages → Build and deployment → Source: GitHub Actions** (если не выбрано).
3. Вкладка **Actions** → дождаться успешного выполнения **Publish Electropanel preview**.
4. Открыть: https://antonschtrading-prog.github.io/electropanel/

При обновлении загрузить новую версию ZIP с именем `electropanel_web_preview_v0.11.zip` или другим именем по шаблону `electropanel_web_preview_v*.zip`. Рабочий процесс выбирает архив с наибольшим номером версии, распаковывает проект и выполняет тесты.

**Ограничение:** приложение является предварительной версией. Расчёты, подключение клемм и нормативная пригодность не подтверждены для проектирования и монтажа.
